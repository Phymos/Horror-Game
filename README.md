Interred
A short first-person horror game set in a graveyard.
Find the key, escape the monster, get out.
Built With

Unity 6
C#

Features

NavMesh AI with state machine (Idle / Patrol / Chase)
Sound-based monster awareness system
Blink mechanic — look away and it moves closer
Two areas: surface graveyard and underground dungeon
URP with pixelated visual style
