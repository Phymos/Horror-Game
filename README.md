# Interred

A short first-person horror game set in a graveyard.

Find the key, escape the monster, get out.

## Built With
- Unity 6
- C#

## Features
- Statue monster with freeze-when-looked-at mechanic
- Sound-based monster awareness
- Key & door interaction system
- Two areas to explore
